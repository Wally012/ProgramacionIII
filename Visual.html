Lapropiedad DisplayEspecifica eñl tipo de cuadro de reprecentaciopn utilizado para un elemento. Es una de las propiedades de CSS mas importates para el control del diseño.

Valores comunes

  • block: El elemento genera un cuadro de bloque, ocumando todo el ancho disponible

  • inline-bloc: Similar a inline pero permite establecer width y heigh

Box Model

Descripcion

El Box Model (Modelo de caja) es fundamental en CSS. Cada elemento es representado como una caja rectangular con las siguientes partes Contenido ,padding, border y margin.

propiedades relacionadas

  • width: Ancho de Contenido
  • height: Alto de Contenido
  • padding: Espacio ente el contenido y el borde
  • border: Borde al rededor del padding y el contenido
  • margin: Espacio exterior, fuera del borde
  • box-sizing: Cambia como se calculan el ancho y el heght

Ejemplos de codigo


                        .caja{
                            width: 200px;
                            height: 100px;
                            padding: 20px;
                            boder: 5px solid #4361ee;
                            margin: 30px;
                        }

                        /*boder-box include padding y border en el widht/height */
                        .caja-inteligente{
                            box-sezing: border-box;
                            width: 200px;
                            padding: 20px;
                        }

    CSS GRID

    Descripcion

    CSS GRIDes un sistema layout bidimencional que permite crear diseños complejos mediante la definicion de filas y columnas. Es ideal para estructuras generales de pagina.

    Propiedades principales

    • Display: grid: Define las columnas
    • : Define las filas
    • grid-template-rows: Espacio en
    • gap: espacio entre seldas
    • grid-area: especifica ubicacion y tamaño de un elemento
    • grid-template-areas: Define un template con nombres

    Ejemplo de codigo

    
                        .contenedor-grid{
                            display: grid;
                            grid-template-columns: 1fr 2fr 3fr;
                            grid-template-rows: 100px auto 100px;
                            gap:15px
                        }

                        .cabecera{
                            grid-column: 1/4; /*osupara desde la linea 1 a 4*/
                        }

    Transform

    Descripcion

    La propiedadtransformPermite modificar visualmente un elemento mediante rotacion, escala, inclinacion o traslacion. estas transformaciones no afectan el laysout al rederdor del elemento.

    Funciones comunes

    • traslate: Mueve el elemento en el plano.
    • Rotate: Rota el elemento: (Grados o radianes)
    • scape: Escala el elemento ( Aumenta o disminuye la altura)
    • skew: Inclina el elemento
    • Matrix: Combina todas las tranformaciones

    Ejemplo del coigo

    
                        .rotar{
                            transform: rotate(45deg);

                        }

                        .escalar{
                            transform: scale(1.2);

                        }


                        .move{
                            transform: traslate(50px, 20px);
                        }


                        .combinar{
                            transform: rotate(20deg) scale(1.1) traslate(30px);
                        }
