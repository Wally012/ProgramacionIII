El DOM (Document Objet Model) es la representacion en forma de arbol del html JavaScript puede leer y modificar ese arbol en tiempo real.

Metodos clave para selecciona elementos:

  • document.getElementById("id")
  • document.querySelector(".clase") -> El primero que coincida.
  • document.querySelectorAll(".clase") -> todos (NodeList)

3. Event Listener

3.1 ¿Que es un evento?

Un evento es una accion que ocurre dentro del navegador: un clic, una tecla de envio de formulario, un scroll, etc. Los listeners son funciones que reaccionan a esos eventos.

3.2 Eventos mas usados

Clic

clic del usuario sobre un elemento.

Input

Se dispara cada vez que el eusuario escribe.

Change

Cuando el valor de un campo cambia y pierde foco.

Submit

Envio de un formulario

Keydown/ keyup

Cuando se presiona o se suelta una tecla.

Mouseover/ Mouseot

Cuando el cursor entra o sale de un elemento.

5.Introduccion a Jquery

5.1 ¿Que es Jquery?

Jquery es una libreria de Java Script Creada con el fin de simplificar la manipulacion del DOM (Document Objet Model), el manejo de eventos y peticiones AJAX. Aunque hy existen alternativas modernas (React o VueJS), pero enternder Jquery sigue siendo util por su presencia en proyectos.

Su lema: "Write this, do more" (Escribe menos, haz mas).
